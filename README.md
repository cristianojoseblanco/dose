# Dose

App de remédios, retiradas no SUS e consultas, instalável no celular (PWA).

- Abra o link no celular e instale: iPhone → Safari → Compartilhar → "Adicionar à Tela de Início". Android → Chrome → "Instalar app".
- Login com código enviado por e-mail (Supabase Auth). Os dados ficam no Supabase, protegidos por RLS: só quem é da casa vê.
- `supabase_schema.sql`: estrutura do banco.

Nenhum dado pessoal fica neste repositório.
